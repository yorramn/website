# Yorramn Dev

Site institucional estatico, criado com HTML, CSS e JavaScript puro.

## Desenvolvimento local

```bash
npm start
```

O site fica disponivel em `http://localhost:3000`.

## Producao

```bash
npm run build
```

O comando gera a pasta `dist` com todos os arquivos necessarios para publicacao.

## Estrutura

- `index.html`: conteudo semantico, SEO e dados estruturados.
- `styles.css`: identidade visual e responsividade.
- `script.js`: navegacao, animacoes e formulario EmailJS.
- `assets/`: logo e favicon.
- `llms.txt`: resumo institucional para agentes de IA.
